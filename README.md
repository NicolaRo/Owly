# Owly

A JavaScript-based book exploration application integrating the Open Library API to search, filter, and display detailed book information through an interactive and responsive interface.

The application allows users to discover books by different criteria, explore search results in multiple layouts, and access detailed information through a dedicated view.

Built to demonstrate API integration, asynchronous data handling, user interaction patterns, and frontend architecture.

---

## Features

- 🔎 Search books by title, author, or category
- 📚 Retrieve book data through Open Library API
- 📝 Display structured search results
- 🔄 Switch between list and grid views
- 📖 View detailed book information through a modal interface
- 🔗 Perform additional API requests for extended book data
- 📱 Responsive interface across devices

---

## Tech Stack

- JavaScript
- Open Library API
- HTML
- CSS
- REST API Integration

---

## Use Case

Owly provides a simple and focused experience for discovering books through external data sources.

The application manages the complete search flow, from user input to API communication and detailed information retrieval, presenting complex data through an accessible interface.

---

## Highlights

- External API integration
- Asynchronous request handling
- Dynamic content rendering
- User-driven filtering
- Multiple data visualization modes
- Responsive frontend development
